# Детекция токсичных сообщений / Классификация токсичных комментариев

Классификация токсичных комментариев с определением типа токсичности: оскорбление, угроза, сарказм и т.д.

## Годовой план

### Основная задача

Детекция и классификация токсичных комментариев с определением типа токсичности: оскорбление, угроза, сарказм и т.д.

### Подзадачи

1. Собрать или найти русскоязычный датасет токсичных и нейтральных сообщений.
2. Провести разведочный анализ данных (EDA).
3. Разработать и обучить модели классического ML.
4. Обучить и сравнить DL-модели (Bi-GRU, BERT).
5. Провести валидацию, настроить гиперпараметры.
6. Разработать веб-приложение или Telegram-бот для демонстрации.
7. Подготовить презентацию к защите.
8. Успешно защитить проект.

## План

### Этап 1. Сбор данных

Чекпойнт 2. Разведочный анализ данных (EDA)

**Предварительный дедлайн:** 27.10.2026

**Задачи:**
- Создать или найти датасет с токсичными и нейтральными сообщениями на русском языке.
- В случае создания с нуля:
  - выполнить парсинг комментариев на русском языке с различных платформ (например, Kinopoisk, VK, Отзовик, iRecommend, Хабр, а также отзывы на маркетплейсах Ozon, Wildberries, Яндекс Маркет);
  - сформировать выборку токсичных и нейтральных сообщений;
  - определить классы: нейтральный, оскорбление, угроза, сарказм, ненависть, мат.
- В случае использования готового датасета рассмотреть возможные варианты:
  - [Russian Language Toxic Comments Dataset](https://www.kaggle.com/) (Двач, Пикабу);
  - [RuSentiment](https://github.com/text-machine-lab/rusentiment) (датасет, собранный из постов во ВКонтакте);
  - [MonoHime](https://huggingface.co/datasets/MonoHime/ru_sentiment_dataset);
  - [RuReviews](https://github.com/sismetanin/rureviews) (отзывы на товары).

**Результат:** размеченный датасет, готовый к дальнейшему использованию.

### Этап 2. Предобработка данных

Чекпойнт 2. Разведочный анализ данных (EDA)

**Предварительный дедлайн:** 27.10.2026

**Задачи:**
- Выполнить очистку текста, нормализацию, удаление стоп-слов и лемматизацию.
- Добавить пробелы вокруг символов, кроме букв и цифр.
- Применить токенизацию и коррекцию ошибок для слов, отсутствующих в словаре (OOV).

**Результат:** обработанный датасет.

### Этап 3. Разведочный анализ данных (EDA)

Чекпойнт 2. Разведочный анализ данных (EDA)

**Предварительный дедлайн:** 27.10.2026

**Задачи:**
- Проанализировать баланс классов (токсичные / нетоксичные / типы токсичности).
- Изучить распределение длин комментариев.
- Выполнить частотный анализ слов и n-грамм по классам.
- Построить визуализации: word clouds, гистограммы, распределения.
- Выявить дисбаланс классов и аномалии.
- Сформулировать гипотезы для моделирования.

**Результат:** выводы по результатам EDA.

---

### Этап 4. Разработка классического ML-классификатора

Чекпойнт 3. Первые ML-модели

**Предварительный дедлайн:** 27.11.2026

**Задачи:**
- Отобрать и применить алгоритмы классического ML:
  - логистическая регрессия;
    - плюсы: простая и быстрая в обучении модель, с TF-IDF даёт хороший результат [6];
    - минусы: может не увидеть сложных зависимостей из-за линейности;
  - метод опорных векторов (SVM);
  - наивный Байес;
  - Random Forest;
  - градиентный бустинг (CatBoost, XGBoost, LightGBM).
- Сравнить алгоритмы между собой.
- Интегрировать статистические признаки (количество слов, уникальных слов, символов и заглавных букв) в модель.

**Результат:** отобранные ML-модели, результаты сравнения

---

### Этап 5. Обучение, валидация и оптимизация

Чекпойнт 3. Первые ML-модели

**Предварительный дедлайн:** 27.11.2026

**Задачи:**
- Разделить данные на Train / Validation / Test.
- Сравнить точность различных моделей на тестовом датасете.
- Использовать различные техники обучения, такие как адаптивная длина последовательностей для RNN на каждом батче и усреднение предсказаний нескольких моделей.
- Оценить качество по метрикам: F1-score (macro/micro), Precision, Recall, дополнительно ROC-AUC, PR-AUC.
- Выполнить анализ ошибок для улучшения предобработки.
- Настроить гиперпараметры:
  - оптимизировать параметры моделей для повышения точности детекции;
  - настроить гиперпараметры на основе надёжного кросс-валидационного (CV) анализа.

**Результат:** обученные модели с оптимизированными гиперпараметрами.
